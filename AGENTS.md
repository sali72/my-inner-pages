# My Inner Pages

AI-powered private journaling app. Backend: FastAPI + MongoDB. Frontend: React + Vite.

## Root-level commands
- `make backend` — start backend dev server (uvicorn --reload)
- `make frontend` — start frontend dev server (Vite, port 5173)
- `make run` — start both backend and frontend concurrently
- `make stop` — kill both processes
- `docker compose up` — full-stack Docker (dev)

## Repo layout
- `backend/` — FastAPI API server → see `backend/AGENTS.md`
- `frontend/` — React SPA → see `frontend/AGENTS.md`

## Production architecture (zero-downtime deploy)

### Frontend
No container — nginx on the host serves static files directly from `/srv/frontend/current/`. Deploy extracts `dist/` from the Docker image, writes to `/srv/frontend/releases/$SHA/`, then atomically swaps the `current` symlink. Last 3 releases are retained (~588KB each).

### Backend
Blue/green via `docker run`. Two slot containers (`backend-blue` on port 8000, `backend-green` on port 8001). Deploy starts the new one, health-checks it, then rewrites `/etc/nginx/conf.d/backend-upstream.conf` and reloads nginx. Old container is stopped only after the new one is healthy and nginx has swapped. Old Docker images are pruned to keep only the last 1 (current) per repo.

### MongoDB
Single instance via `docker compose up -d mongodb --no-build` (network: `my-inner-pages_app-network`).

### Nginx
- Host-installed, configured from `nginx/` in the repo
- `nginx.conf` includes `include /etc/nginx/conf.d/*.conf` — auto-loads both `backend-upstream.conf` and `innerpages.ir.conf`
- `backend-upstream.conf` is generated by the deploy script (defines `upstream backend`)

### Deploy safeguards
- **Disk guard**: aborts if <2GB free on `/` before any operations
- **Migration cleanup**: stops/removes old-style `journaling-backend`/`journaling-frontend` containers on first run
- **Concurrency**: cancels-in-progress disabled — one deploy blocks another to prevent races on the VPS

### Key files
- `.github/workflows/deploy-vps.yml` — CI build + zero-downtime deploy
- `nginx/innerpages.ir.conf` — serves frontend from `/srv/frontend/current/`, proxies API to `http://backend`
- `nginx/backend-upstream.conf` — default upstream (port 8000), overwritten by deploy

## General conventions
- **Simplicity first:** prefer the most maintainable solution, avoid unnecessary complexity
- Commit messages: imperative mood, scope-prefixed (`feat:`, `fix:`, `refactor:`, `test:`, `docs:`)
- Never commit `.env` files, secrets, or credentials
- Lockfiles (`package-lock.json`, `uv.lock`) committed on dependency changes
- Keep `AGENTS.md` files updated alongside code changes in the same PR
